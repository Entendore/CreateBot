1 · THE MACHINE

        
The CREATE-BOT CB-6 is a pattern composer. Its first job is creation: repainting blank crates
          to a spec with the ink head (bot.ink). Along the way it also learned to arrange cargo into
          order and to group it by property — useful, but secondary. You write Lua that drives the head.
          Certification runs every randomized test tape in the batch; par is judged on the total and earns
          the efficiency star.

        
2 · THE COMMISSION BOARD

        
The COMMISSIONS button posts a board of three procedurally generated commissions — a goal
          (paint spec, arrangement key, partition predicate…), a tape shape, and restriction mutators (NO
          bot.cmp, NO bot.at, NO bot.find, NO bot.swap) composed
          into fresh work with its own computed budget and par. Three tiers — NOVICE · JOURNEYMAN · FOREMAN —
          with 30 problem families; harder ones appear only at higher tiers. Every board has a seed: share it and a
          friend gets identical commissions. Solving never ends; the board refills itself.

4 · THE BOT — EVERY CALL COSTS 1 OP

        

          

            bot.ink(i, k)
            —
            The hero verb. Repaint slot i with pattern code k (1–9).
          

          

            bot.len()
            → n
            Number of slots. Cache it — repeats cost ops.
          

          

            bot.at(i)
            → code
            Cargo code of slot i (1-based).
          

          

            bot.find(k)
            → i
            Smallest slot holding pattern code k, or 0 if none.
          

          

            bot.class(i)
            → 1–4
            Class: 1 PLAIN · 2 LINED · 3 DOTTED · 4 GRID.
          

          

            bot.cmp(i, j)
            → −1|0|1
            Compares codes (classes in class-group bays).
          

          

            bot.swap(i, j)
            —
            Exchange any two slots, any distance, same price.
          

          

            bot.wish(i)
            → code
            The code that belongs in slot i. Manifest work only.
          

          

            bot.mark(i, s)
            —
            FREE. Chalk a note onto slot i. 400 per run.

8 · WORKED EXAMPLES

        
a) Paint by parity. Creation is mapping: the loop variable decides, the ink head executes.

        
local n = bot.len()          -- 1 op
for i = 1, n do              -- visit every slot
  if i % 2 == 1 then
    bot.ink(i, 2)            -- odd: STRIPES
  else
    bot.ink(i, 3)            -- even: DOTS
  end
end

        
b) The read-once pattern. For arrangement work: snapshot once, plan on the copy for free, apply only
          what matters.

        
local n = bot.len()
local cur = {}
for i = 1, n do cur[i] = bot.at(i) end
-- ...plan on the copy (0 ops)...
-- ...then swap / ink only what differs

        
c) A scratchpad session.
